Noren is a terminal organized like a modern browser.

After years of terminal sessions that grow into dozens of tabs (servers, builds, scratch shells, one repository per project), I wanted the organization browsers already solved: spaces, groups, pinned tabs and a search box that finds anything.

So I am building Noren. What it does today:

- Spaces, each with its own tabs, color, theme and git identity
- A sidebar tree of groups and tabs showing folder, git branch and last command
- Splits created by dragging a tab onto a pane
- One command palette for tabs, actions, profiles and themes
- A default shortcut preset that leaves Ctrl+T and Ctrl+W to the shell
- Optional AI that is off until you set it up, shows what it will send, and never runs a command for you
- No account and no telemetry

It is built on Tauri 2 and Rust with a React interface, runs on Windows first, and is MIT licensed. It is pre-alpha: there is no public release yet, and builds are not code-signed.
